# System Directives for AI4Stock2

## Execution Protocol
- **STRICT MANUAL EXECUTION**: The user MUST manually execute all core Python scripts (e.g., `main.py`, data collectors, model trainers). 
- Do **NOT** use `run_shell_command` to execute these on the user's behalf under any circumstances.
- The AI's role is strictly to write code, modify configurations, and instruct the user on what commands to run next.
